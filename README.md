# AI-Guided Human Development

A framework for systematic self-development guided by AI.
It shows how to use AI as a mentor: setting goals,
structuring learning, and tracking progress through
well-designed prompts.

## Why

Most people learn chaotically. An AI curator turns
self-development into a system — with a plan, feedback,
and measurable results.
